# 古诗词默写打卡

小学 · 中考 · 高考 · 文言实词 · 英语词汇，六款正版学习产品。
背诵打卡、默写练习、打字填词、自动判分，手机 / 电脑浏览器直接打开，无需安装。

## 网页版（直接使用）

- 主页：https://gushicikada.pages.dev/
- 小学生必背古诗词 75 首：`xiaoxue75.html`
- 中考古诗文 102 篇：`zhongkao102.html`
- 高考古诗文 60 篇 · 真题版：`gaokao60_zt.html`
- 高考古诗文 60 篇（基础版）：`gaokao60.html`
- 文言文常用实词 120：`shici120.html`
- 高考英语词汇 3500：`gaokao_english.html`（音标 · 朗读 · 例句填空 · 看义拼词）

网页文件下载到手机 / 电脑后，直接用浏览器打开即可离线使用。

## 安卓 App

- `gushicikada-android.apk`：安卓安装包（6 款产品全部内置）
- `gushicikada-android.zip`：备用压缩包（内含安装包和安装说明）

微信里打不开 APK 时，请用浏览器下载，或使用 ZIP 备用包。

## 使用说明

1. 首次打开需输入「购买时登记的姓名 + 授权码」激活，一个授权码对应一个孩子；
2. 打卡记录保存在本机浏览器 / App 内，换手机前请先在「设置 → 备份」导出；
3. 没有授权码请联系卖家购买。
